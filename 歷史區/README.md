# MemoPen 歷史區

這裡收存 MemoPen 的舊版號檔案。GitHub 根目錄只保留最新版，舊版依版本號分資料夾保存。

## 已收存版本

- `V0.14/`：原始 `MemoPen_V0.14_Nuitka_Package.zip` 內容。
- `V0.14.1/`：上一版 Git 發布檔案，包含 `.py`、`.pyw`、Nuitka 建置檔、說明與文件。
- `V0.14.2/`：上一版 Git 發布檔案，包含 `.py`、`.pyw`、Nuitka 建置檔、說明與文件。
- `V0.14.3/`：修復無標題列視窗四邊、四角與右下角尺寸拉伸功能的完整版本。
- `V1.0.0/`：保留空白新筆記開舊檔時的清理功能與 V1.0.0 發行文件。
- `V1.1.4/`：導入十階編碼、升降階、系統匣、字體調整與事件式自動儲存的已發布版本。

## 最新版

最新版請回到 repo 根目錄使用 `MemoPen_V1.1.5.py` 或 `MemoPen_V1.1.5.pyw`。
